# ISOPC 🖥️

Интернет-магазин компьютерной техники с возможностью сборки ПК под заказ.

## 📄 Страницы

| Файл | Назначение |
|------|-----------|
| `index.html` | Главная страница |
| `catalog.html` | Каталог товаров |
| `build-pc.html` | Конфигуратор сборки ПК |
| `ready-pcs.html` | Готовые сборки |
| `single.html` | Карточка товара |
| `cart.html` | Корзина |
| `services.html` | Услуги |
| `about.html` | О компании |
| `log.html` | Вход |
| `reg.html` | Регистрация |

## 🛠️ Технологии

- HTML5
- CSS3
- JavaScript
